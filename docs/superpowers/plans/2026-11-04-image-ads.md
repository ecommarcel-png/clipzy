# Image ads Implementation Plan

> Executed inline (superpowers:executing-plans). Spec: `docs/superpowers/specs/2026-11-04-image-ads-design.md`.

**Goal:** Narzędzie `/image-ads`: N (1–20) reklam graficznych 1:1 + 9:16 z copy, automatycznie, z Kontrolerem.

**Architecture:** Dane w `image_ad_sets`/`image_ads` (migracja 0006). Czyste moduły w `src/lib/image-ads/` (steps, templates/schematy, layouts), render `next/og` na serwerze, agenci w `src/lib/ai/image-ads.ts`, fal w `src/lib/ai/fal-image.ts`, wykonawcy kroków w `src/lib/image-ads/pipeline.ts`, akcje + UI w `src/app/(app)/image-ads/`.

## Global Constraints
- Formaty wyjścia: 1:1 = 1080×1080, 9:16 = 1080×1920; jedno zdjęcie 1:1 na kreację (przed/po: dwa).
- N: 1–20 (krok 1). Copy: nagłówek ≤ 40 zn., opis ≤ 30 zn., tekst główny ≤ 900 zn.
- Opinie wyłącznie z `social_proof` produktu; przed/po zawsze, gdy `before_after.possible`.
- Każdy krok serwera < 300 s; partie: copy/grafik/fotograf po 5, render po 4, Kontroler po 3, fal submit po 6.
- Brak migracji 0006 → strona pokazuje komunikat, nic nie wybucha.
- Polskie znaki: tylko fonty z `assets/fonts` (Inter, Anton, Bricolage Grotesque, Caveat).
- Klucze BYOK: anthropic + fal (brak → czytelny błąd z linkiem do Ustawień).

## Review Focus
- Brak zdjęć produktu → fal text-to-image, szablony z packshotem używają zdjęcia sceny (Task 3/5).
- Za długi tekst w polu → przycięcie w schemacie + auto-dopasowanie rozmiaru fontu w układzie (Task 2/3).
- Błąd fal / timeout zdjęcia → kreacja dostaje błąd i „Spróbuj ponownie”, reszta leci dalej (Task 1/6).
- Wyjście ze strony w trakcie → powrót wznawia od stanu z bazy (Task 1/7).
- Produkt bez social proof → Strateg nie wybiera testimonial (Task 4).
