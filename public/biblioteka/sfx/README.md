# Biblioteka efektów dźwiękowych (SFX)

Krótkie efekty (MP3/WAV, do kilku sekund), których Reżyser używa przy efektach montażowych. **Pierwsze słowo nazwy pliku to kategoria** — po nim Reżyser wie, do czego służy dźwięk:

| Kategoria | Kiedy gra |
|---|---|
| `whoosh-…` | przejścia między scenami, wipe w kolorze marki |
| `pop-…` | wyskakująca ikona, etykieta, badge |
| `strike-…` | przekreślenie ikony („bez maszynki”) |
| `ding-…` | ✓, pozytywny efekt, korzyść |
| `sparkle-…` | błysk, iskierki, efekt gładkości/blasku |
| `rip-…` | zerwanie, ból, gwałtowny moment problemu |
| `swipe-…`, `click-…`, `cash-…`, `impact-…` | inne — dopisz kategorię, Reżyser ją zobaczy |

Przykłady nazw: `whoosh-krotki.mp3`, `pop-miekki-2.mp3`, `ding-dzwonek.mp3`.

Kilka plików z tej samej kategorii = więcej różnorodności (Reżyser wybiera różne). Pliki startowe (`*-1.mp3`) wygenerowano w ElevenLabs Sound Effects przez fal.ai.
